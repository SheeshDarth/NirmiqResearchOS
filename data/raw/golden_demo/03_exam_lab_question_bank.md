# Golden Demo Source 03: Exam Lab Study Notes

Exam Lab exists because academic answers are not all the same shape. A two-mark answer should be short and direct: it should give a compact definition and one key point. A five-mark answer should include definition, key points, and one example. A ten-mark answer should include an introduction, structured headings, explanation, limitations or applications, and a concise conclusion. The answer should still come from the uploaded source material.

For a ten-mark answer on citation-grounded retrieval, the expected structure is:

1. Define citation-grounded retrieval as a method that answers questions using retrieved source chunks and visible citations.
2. Explain the pipeline: document parsing, chunking, retrieval, fusion, synthesis, verification, and citation display.
3. Explain why it reduces hallucination: the model must rely on retrieved evidence and should abstain when evidence is weak.
4. Mention local-first privacy: documents stay on the user's machine and selected material can be removed.
5. Mention limitations: poor scans, missing OCR, weak source material, or unrelated questions can reduce answer quality.
6. End with a conclusion that grounded academic systems are useful because users can inspect claims instead of trusting a black box.

Important exam questions for the golden demo:

Q1. Explain citation-grounded retrieval and its role in reducing hallucination. (10 marks)
Q2. Differentiate between generic AI chat and a document-grounded academic assistant. (5 marks)
Q3. Why is source inspection important in academic AI systems? (5 marks)
Q4. List privacy measures used by a local-first academic assistant. (5 marks)
Q5. When should an academic assistant abstain from answering? (2 marks)

The answer format should be clear, marks-ready, and easy to revise. Citations should remain visible because exam preparation must still be faithful to the source material.
