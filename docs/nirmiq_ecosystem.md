# NIRMIQ Ecosystem Positioning

Last updated: 2026-05-30

## Umbrella

NIRMIQ is a local-first AI operating ecosystem for builders who want to learn, remember, discover, coordinate, and execute using personal intelligence infrastructure.

## Current Product

The current repository is now branded as:

**NIRMIQ Academic Intelligence System**

This product must work independently as a complete academic/document intelligence workspace. It should not require the rest of the NIRMIQ ecosystem to be useful.

## Ecosystem Modules

### NIRMIQ OS

Core platform and dashboard for local AI workflows, automation, projects, memory, tools, and orchestration.

### NIRMIQ Mirror

Personal context engine that remembers notes, projects, ideas, learning history, and how the user's knowledge evolves over time.

### NIRMIQ Intelligence Engine

Opportunity intelligence system for monitoring trends, communities, startups, creators, emerging niches, and content/project gaps.

### NIRMIQ Agent System

Transparent task coordination engine that decomposes work, assigns specialist agents, keeps decision logs, and supports explainable workflow execution.

### NIRMIQ Academic Intelligence System

Offline-first learning, research, paper, citation, and exam intelligence system. It organizes documents, retrieves grounded evidence, supports paper drafting, and helps students build study guides from their own sources.

### NIRMIQ Echo

Voice assistant layer for interacting with NIRMIQ workflows, memory, and tools through speech.

### Ascension OS

Adjacent product track for a local-first personal execution operating system. Ascension OS is not part of the current academic product, but it can later connect to the NIRMIQ ecosystem through explicit adapters.

## Standalone Product Rule

NIRMIQ Academic Intelligence System must remain valuable on its own:

- Upload documents.
- Ask grounded questions.
- Summarize PDFs.
- Inspect citations.
- Draft paper sections.
- Generate exam answers and study guides.
- Run offline-first on consumer hardware.

The rest of the ecosystem should enhance it, not become a dependency.

## Integration Philosophy

- NIRMIQ OS can eventually launch and orchestrate this product.
- NIRMIQ Mirror can eventually provide personal long-term context.
- NIRMIQ Intelligence Engine can eventually suggest research/project opportunities.
- NIRMIQ Agent System can eventually coordinate deeper research workflows.
- NIRMIQ Echo can eventually provide voice control.

For V3, this repository stays focused on the Academic Intelligence System.
